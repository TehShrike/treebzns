Design notes

  • Scheduling is two screens. This one answers "who works where this week" and holds the worker assignments. The crew day screen answers "what does this crew do on this day" and holds the job assignments and the map.
  • A cell is one crew on one day. The worker pills start from crew_regular and the Edit button swaps people for that day only.
  • "Open the day" goes to the crew day screen with that crew and date already picked.
  • Skills are checked, not enforced. The warning panel compares what the week's jobs need against what the assigned people hold. Andrew can ignore every warning.
  • Estimating is a crew row like any other. An estimate visit is still a project_crew row.
  • Open: a per-day worker swap has nowhere to write. project_crew_employee hangs off a visit, so a day with no visits can not record "Trevor covers for Dale". Does the swap write to every visit that day, or does a crew-day roster table need to exist?
  • Open: crew capacity. "11 of 10 hours" needs an hours-per-day number per crew. Nothing in the schema holds it. Add crew.hours_per_day, or drop the warning?
  • Open: time off. "Dale off Wednesday" has no table behind it.
